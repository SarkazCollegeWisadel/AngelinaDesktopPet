# 安洁莉娜 Windows 桌宠

一个使用 PySide6 制作的透明、无边框 Windows 桌面宠物。角色素材来自项目所有者提供的图片，程序面向本地个人使用。

## 已实现

- 透明无边框窗口、始终置顶开关、左键拖动、滚轮缩放（120–700px）
- 点击轮换跳跃、压扁回弹和左右抖动；拖动释放有惯性、重力和边缘反弹
- 随机待机 GIF、随机走动/折返，动作会按实际移动或拖拽方向自动翻转
- 不操作较久后主动搭话；本地台词断网可用
- 右键“递给她一本书”可停止走动；“小链子”可在桌面点选固定点，限制活动范围并显示链条
- 右键“让她去指定地点”可在桌面点选目的地，她会选择一种移动动作走过去
- 办公彩蛋：连续输入后切换到电脑桌前，用蓝色胶囊实时显示键名并触发轻微 Q 弹/星星反馈；不在图片键帽上叠加错位高光，也不保存或发送键入内容
- 奶油色不透明对话气泡自动避开角色、停留更久；点击后在角色附近打开始终置顶的二次元小聊天气泡，只显示最近两轮
- 系统托盘、位置/大小记忆、开机启动
- OpenAI Chat Completions 兼容文本 AI：默认 Step Plan `step-3.7-flash`，也可填写 DeepSeek 地址和模型
- 手动或定时屏幕理解：默认 Step Plan `step-3.7-flash`；定时模式可设 5–240 分钟，截图只驻留内存、不落盘
- API Key 使用当前 Windows 用户的 DPAPI 加密保存

## 直接运行

解压发布包后运行：

`AngelinaDesktopPet.exe`

基础操作：

- 左键拖动安洁莉娜；快速拖出后松手会有惯性、落地和反弹。
- 轻点角色依次触发跳跃、压扁回弹、左右抖动。
- 鼠标滚轮调整大小；右键打开聊天、动作、书本、小链子、走动和系统选项。
- 右键选择“让她去指定地点…”，再在桌面左键点一下；按 Esc 或右键可取消选点。
- 右键选择“系到指定地点…”，再点选链子固定点；安洁莉娜会走到附近，固定点会跨启动保存。
- 连续输入约六次会自动触发办公彩蛋；也可右键选择“拉出小键盘办公”。办公状态会用蓝色胶囊显示当前键名，并以短促 Q 弹和星星回应；点击角色还会触发猫爪鼠标反馈。
- 右键“递给她一本书”后会原地看书，再点角色或再次选择菜单即可收书。

首次使用 AI 时进入“AI 与隐私设置”，在本机填写 Step Plan 或 DeepSeek 的完整 API Key。不要把完整 Key 发到聊天或提交到仓库。
填写后可先点“测试连接”；聊天窗口会区分“已配置”“连接正常”和“连接失败”。
如需主动陪伴，可在“屏幕理解”页开启定时观察并设置间隔；关闭开关后计时器立即停止。

Step Plan 默认配置：

- Base URL：`https://api.stepfun.com/step_plan/v1`
- 文本/视觉模型：`step-3.7-flash`

DeepSeek 兼容配置示例：

- Base URL：`https://api.deepseek.com`
- 模型：使用账户当前可用的模型 ID

## 从源代码构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

脚本会创建 `.venv`、安装依赖、处理透明动画、运行测试、生成 `dist/AngelinaDesktopPet/AngelinaDesktopPet.exe`，并输出 `release/AngelinaDesktopPet-Windows-x64.zip`。

开发模式：

```powershell
.\run.ps1
```

## 用 Skill 复现自己的桌宠

仓库内置 [`build-windows-desktop-pet`](skills/build-windows-desktop-pet/SKILL.md) Skill。把 `skills/build-windows-desktop-pet` 复制到个人 Codex 的 `~/.codex/skills/` 后，可使用自己的 PNG/GIF 角色图片复现同类 Windows 桌宠。

Skill 启动时会先询问角色图片和仅用于连接试验的 API Key；真实 Key 不会写入 Skill、源码或 Git 历史。

## 隐私边界

- 全局键盘钩子只把单个按键类别交给本地高亮动画，内存仅保留最近 4 秒的按键时间点。
- 程序不拼接键入内容、不写按键日志、不把按键发送给模型。
- 手动屏幕观察每次都会确认；定时观察仅在你主动开启后按设定间隔运行，不再逐次弹窗。
- 截图前会隐藏桌宠、链条和聊天气泡；截图仅在内存中缩放、压缩并发送，不写入文件。
- 模型可能误判屏幕内容，输出只用于轻量陪伴，不用于重要决策。
